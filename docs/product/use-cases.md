# Use Cases

## Same-Machine Test

Open two tabs on `localhost` and verify signaling.

## Same-LAN Call

Run the server on one machine and connect from another using the host LAN IP.

## SSH-Forwarded Call

Forward `4000` to a remote host, then access the app on local `localhost`.

## Isolated LAN Fallback

Start local TURN relay and point clients at the relay when direct ICE fails.
