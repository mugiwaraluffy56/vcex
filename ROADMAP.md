# Roadmap

## v0.1 - LAN Call Foundation

- Stable browser call flow.
- Tauri desktop development flow.
- Room URLs.
- Local health check and smoke test.
- Basic network troubleshooting docs.

## v0.2 - Call Ergonomics

- Camera and microphone pickers.
- Mute controls.
- Screen share.
- Connection status.
- Copy invite link.
- Room cleanup and reconnect behavior.

## v0.3 - Network Resilience

- Local TURN profile.
- Diagnostics panel for ICE state, bitrate, RTT, and packet loss.
- Better relay fallback messaging.
- Optional HTTPS mode.

## v0.4 - Controlled Sharing

- Room access tokens.
- Optional local auth gate.
- Host allowlist.
- Rate limits and connection caps.

## Later

- File transfer over WebRTC data channels.
- Local chat.
- Recording.
- Packaged desktop installers.
- Mobile-friendly layout pass.
