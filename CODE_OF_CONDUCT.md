# Code of Conduct

This project follows a simple standard: be direct, constructive, and respectful.

## Expected Behavior

- Assume good intent.
- Keep feedback actionable.
- Discuss technical tradeoffs with evidence.
- Respect different experience levels.

## Unacceptable Behavior

- Harassment or personal attacks.
- Publicly sharing private information.
- Repeatedly derailing technical discussion.
- Using the project to harm networks or users.

Report problems to the repository owner.
