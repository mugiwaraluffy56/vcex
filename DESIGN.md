# Design

vcex should feel like a small operations tool for private calls, not a consumer social app.

## Product Personality

- Quiet.
- Technical.
- Trustworthy.
- Fast to scan.
- Clear about network state.

## Interface Principles

- The call surface is primary.
- Connection status is always visible.
- Network failures should name the likely cause.
- Controls should be compact and familiar.
- Desktop and browser wording should match.

## Visual Direction

- Neutral base colors.
- High contrast text.
- Minimal decoration.
- Compact controls with clear labels.
- Status colors reserved for meaningful state.

## Core Screens

- Join/create room.
- Active call.
- Device setup.
- Diagnostics.
- Network help.
