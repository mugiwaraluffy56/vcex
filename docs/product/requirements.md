# Requirements

## Functional

- Serve browser client assets.
- Accept WebSocket upgrades.
- Relay signaling between peers.
- Expose health endpoint.
- Provide LAN and SSH helper scripts.
- Support a desktop development shell.

## Non-Functional

- Work offline by default.
- Avoid external runtime services.
- Keep startup fast.
- Keep protocol code readable.
- Keep failure messages actionable.
